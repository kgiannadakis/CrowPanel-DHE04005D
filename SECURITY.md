# Security Policy

Please do not disclose vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository, if available. Otherwise, contact the repository owner privately through their GitHub profile and provide a concise description, affected revision, reproduction steps, and impact.

Never include real Wi-Fi credentials, API tokens, mesh private keys, precise location data, or unredacted device logs in a report.

This is community firmware for embedded hardware. Only the latest revision on `main` is actively maintained, and no response or remediation timeline is guaranteed.
